CSV File Specifications

Column headers must match exactly:

vendor_name, vendor_category, business_owner, security_reviewer, department, service_description, system_supported, data_types_processed, sensitive_data, phi_involved, payment_data, pii_involved, cloud_hosted, country_region, criticality, inherent_risk, residual_risk, review_status, approval_status, onboarding_date, last_review_date, next_review_date, notes

  • criticality: Low / Medium / High / Critical
  • dates: YYYY-MM-DD format
